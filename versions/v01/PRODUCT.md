# Monolith v01 — Common Thread

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Independent static HTML and CSS. No JavaScript, runtime dependencies, build step, backend, or external font requests. Code-first implementation is explicitly selected by the approved v01 plan and recorded in `.impeccable/config.json`.

## Users

Individuals and small teams organizing their work information. This presentation also serves people evaluating the proposed Monolith identity and downloading its reusable vector assets.

## Product Purpose

Monolith is a planned workspace for organizing work information into a connected place that OpenJM can use to assist with real work. The user's comparison to Notion and AppFlowy establishes the workspace/database category, not feature parity. CrimsonTide AI is the parent company; OpenJM and Sentinel are its first products. Monolith may have an independent identity.

## Scope

This version presents the proposed Common Thread identity: “Your work, woven together.” It contains an opening, brand idea, logo system, color and typography, graphic system, and illustrative applications. The orange palette, Sora lettering, woven M, and concept line are v01 proposals, not permanent product-wide commitments.

## Constraints and Open Decisions

All workspace data and applications shown are illustrative. This implements no workspace functionality, synchronization, OpenJM integration, authentication, or publishing. Exact database features, integration behavior, permissions, release timing, pricing, and final product-wide branding remain open. The page must work without JavaScript and with relative URLs under `/monolith/`.
