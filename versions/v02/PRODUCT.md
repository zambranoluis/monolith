# Monolith v02 — Everyday Orbit

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Standalone HTML, CSS, and a small deferred JavaScript file. Built directly in code using Impeccable, as selected in the approved v02 plan. Local fonts and SVG assets; no runtime dependencies, installation, or build. The authoring script uses an isolated Python environment for font subsetting and outlined lettering.

## Users

Individuals, small teams, and reviewers evaluating this proposed identity.

## Product Purpose

Monolith is a planned workspace/database for work information that OpenJM can use to help with real, integrative work. CrimsonTide AI is the parent company. References for that product family provide context, not a visual template or feature contract.

This version presents an independent brand proposal, Everyday Orbit: “Room for your working world.” Notes, Projects, and Knowledge share a useful center, expressed through a physical mobile. It implements neither an application nor an OpenJM integration.

## Operating Context

Visitors explore the concept, rebalance three illustrative forms, inspect the identity toolkit and sample applications, and download reusable SVG artwork. A native return link leads to the concept hub. The workspace application example is explicitly a static illustration with invented sample content.

## Capabilities and Constraints

- Page sequence: opening, product idea, interactive balance study, identity toolkit, illustrative applications, downloads.
- Chalk, cobalt, ink, coral, citrus; local Instrument Sans and Newsreader Italic. Retain font licenses, original sources, and provenance.
- Asymmetric balance symbol: vertical stem, offset crossbar, opposing solid semicircles. Include simplified small-size mark and cobalt app icon.
- Eight self-contained logo/icon downloads with outlined lettering; two reusable mobile-pattern SVGs.
- One Rebalance button cycles three authored arrangements with interruptible 450ms transform motion. Preserve focus and announce arrangement numbers politely. Reduced motion is immediate; without JavaScript the complete first arrangement is visible and the button is omitted.
- Centered 84rem canvas, fluid gutters, stacked layouts below 760px, native scrolling, relative URLs compatible with `/monolith/` and direct-file opening.
- Keep all version context and assets local. Preserve v01, the hub's visual system, and user configuration.

## Open Decisions

Permanent brand adoption, workspace features, data model, permissions, integration behavior, pricing, release, and publishing remain outside this version and belong to the user. The Notion/AppFlowy comparison supplies category context, not feature parity. Illustrative applications establish no functioning capability.
