# Everyday Orbit assets

Original v02 vector artwork, authored directly for the approved Everyday Orbit plan. These are proposed identity assets, independent of v01 and the reference brands.

| Asset | Use |
| --- | --- |
| [Primary symbol](symbol-primary.svg) | Ink balance mark on light grounds. |
| [Reversed symbol](symbol-reversed.svg) | Chalk balance mark on cobalt or ink. |
| [Simplified symbol](symbol-small.svg) | Thicker supports at 16–24px. |
| [Primary wordmark](wordmark-primary.svg) | Outlined ink Instrument Sans lettering. |
| [Reversed wordmark](wordmark-reversed.svg) | Outlined chalk Instrument Sans lettering. |
| [Primary lockup](lockup-primary.svg) | Ink symbol and wordmark. |
| [Reversed lockup](lockup-reversed.svg) | Chalk symbol and wordmark. |
| [App icon](app-icon.svg) | Chalk simplified mark on a cobalt rounded square. |
| [Chalk mobile pattern](mobile-pattern-chalk.svg) | Reusable suspended-weight composition on chalk. |
| [Cobalt mobile pattern](mobile-pattern-cobalt.svg) | Reusable suspended-weight composition on cobalt. |

All ten SVGs are self-contained and scalable, with accessible titles, no external references, scripts, embedded fonts, or font-dependent text elements. Reversed variants have transparent backgrounds and need a dark ground. The patterns and app icon include their background.

Clear space is at least the radius of a semicircular weight (36 units in the primary mark). Do not crop the symbol or use coral as an ordinary text ground. [Font provenance and licenses](fonts/README.md) accompany the local fonts and outlined lettering.
